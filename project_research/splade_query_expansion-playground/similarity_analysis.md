# 元クエリとの類似度で追加語を選ぶ予備実験

保存済みのSPLADE上位3語から語を選ぶ。追加語のBM25寄与は、既存の重み実験で使った `α=0.25` に固定した。文書、qrels、BM25索引は[既存実験](README.md)と同じ。SPLADEの再推論はしていない。

各候補語と元クエリの英字語との類似度は、**元語との最大値**とした。基本的な機能語は除いた。次の2種類を使う。

- **文字列類似度:** Pythonの `difflib.SequenceMatcher`。`card/cards` のような語形の近さを測る。
- **埋め込み類似度:** 使用済みSPLADEモデルのBERT入力埋め込みのコサイン類似度。元語が複数のWordPieceに分かれる場合は平均する。追加のエンコーダ推論は不要だが、入力埋め込みは文脈を考慮した意味類似度ではない。

「高」「低」は上位3語の中で類似度最大・最小の1語を選ぶ。**各条件の追加語は必ず1語**なので、語数の差はない。「重み×類似度」はSPLADE重みをその質問の1位語で割り、類似度を掛けて最大の1語を選ぶ。比較としてSPLADE重み1位語と上位3語全部も載せる。同点ならSPLADE順位が高い語を選ぶ。

## nDCG@10

| 条件 | SciFact | FiQA | ArguAna | NFCorpus |
| --- | ---: | ---: | ---: | ---: |
| BM25のみ | 0.66046 | 0.23585 | 0.30830 | 0.30806 |
| 上位3語すべて | **0.67183** | **0.24005** | 0.30882 | **0.31369** |
| SPLADE重み1位の1語 | 0.66699 | 0.23723 | 0.30801 | 0.31071 |
| 文字列類似度が高い1語 | 0.66312 | 0.23914 | 0.30898 | 0.30970 |
| 文字列類似度が低い1語 | 0.66707 | 0.23415 | 0.30839 | 0.31137 |
| 埋め込み類似度が高い1語 | 0.66194 | 0.23856 | 0.30829 | 0.30951 |
| 埋め込み類似度が低い1語 | 0.66844 | 0.23557 | 0.30871 | 0.30900 |
| SPLADE重み×文字列類似度の1語 | 0.66662 | 0.23762 | **0.30898** | 0.31183 |
| SPLADE重み×埋め込み類似度の1語 | 0.66602 | 0.23647 | 0.30860 | 0.31018 |

高類似度1語と低類似度1語のnDCG@10差（高−低）は、文字列類似度でSciFact `-0.00394`、FiQA `+0.00500`、ArguAna `+0.00059`、NFCorpus `-0.00167`。質問単位3,000回の復元抽出による95%区間は順に約 `[-0.01282, +0.00432]`、`[+0.00050, +0.00985]`、`[-0.00064, +0.00189]`、`[-0.00764, +0.00393]`。同じtest上で複数条件を探索しているので、FiQAの区間だけを根拠に普遍的な改善とは言えない。埋め込み類似度では4データセットすべてで差の区間が0を含んだ。

**観察:** FiQAでは似た1語を選ぶほうが良いが、SciFactでは逆。ArguAnaとNFCorpusでは差が非常に小さい。上位3語を0.25倍で足す既存条件を明確に上回る選び方は、この候補集合では見つからなかった。

## 読み方と制約

- 今回は保存済みの**上位3語だけ**から選ぶ。類似度で候補を捨てたあとに4位以下から補充する方式は未評価。
- 一語の選択では、単語そのものの有用性とSPLADE順位が入れ替わる効果が混ざる。語数を1に固定した比較なので、「高類似度を残せばよい」という一般則の検証には足りない。
- SciFactの質問54では `lung` が文字列類似度最高で改善に寄与する一方、埋め込み類似度最高は `fi` で改善しない。単純な入力埋め込みのコサインは意味の近さを安定して表すとは限らない。
- ArguAnaのSPLADE入力は513/1,406問で256トークン上限に達している。類似度は元クエリ全文から計算しており、モデルが実際に読んだ部分とずれる質問がある。
- どの条件もtestデータを使った探索的な比較で、未使用データへの一般化は未確認。

各質問の候補、2種類の類似度、選択語、nDCG@10・Recall@10・Recall@100は `results/<dataset>/similarity_filters.json` に保存した。再計算は、各データについて `.venv/bin/python similarity_filters.py --dataset scifact` のデータ名を変更して実行する。
